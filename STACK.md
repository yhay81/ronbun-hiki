# Stack

- Cloudflare Workers + Hono JSX
- Vite+ for development, checks, tests, and builds
- Cloudflare Durable Objects for serialized Crossref access and short in-memory reuse
- Cloudflare D1 for allowlisted anonymous product events only
- Plain browser JavaScript and CSS

Accounts and cross-device state are outside the first release, so Better Auth is intentionally not installed.
